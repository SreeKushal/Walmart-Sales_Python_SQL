# Walmart-Sales_Python_SQL 

An end-to-end data analysis project using **Python** and **SQL** to extract insights from Walmart sales data. Covers the full pipeline from **data acquisition** to **business insights**.

## Tech Stack
- Python (Pandas, SQLAlchemy)
- MySQL, PostgreSQL
- Kaggle API

## Key Steps
- Download & clean sales data
- Perform exploratory analysis
- Load data into SQL databases
- Run advanced SQL queries to answer business questions

## Results
- Identified sales trends across locations, products, and time periods
- Analyzed customer behavior and payment patterns
- Provided actionable insights on revenue and profit distribution

➡️ Future improvements: Dashboarding (Power BI/Tableau), automation of data pipelines.

Data Source: Walmart Sales Dataset on Kaggle.
